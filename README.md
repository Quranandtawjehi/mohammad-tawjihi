# 🎓 نظام توجيهي محمد عبد السلام زيادة 2027

صفحة إنجاز خاصة لمحمد، **محمية بكلمة مرور**، وكل البيانات **مشفّرة** (AES-256) بكلمة المرور، على الجهاز وعلى الإنترنت.
اللي معه الرابط وما معه كلمة المرور ما بيشوف ولا إشي.

## الميزات
- 🔒 شاشة قفل: أول مرة بيختار محمد كلمة المرور، وبعدها بيدخل فيها (مع خيار "تذكّرني على هالجهاز")
- 🔑 زر تغيير كلمة السر فوق الصفحة (بيطلب القديمة أول، ومقياس قوة لكلمة السر الجديدة)، وزر 🔒 لقفل الصفحة
- ⏳ عد تنازلي لامتحانات التوجيهي (21/7/2027) وأدعية
- 📚 المواد الأربعة: التربية الإسلامية (26 درس)، الرياضيات (13)، اللغة العربية (25)، تاريخ الأردن (13)
- ✍️ تسجيل الإنجاز اليومي: الصفحات (لكل درس)، الوقت، والدروس اللي خلصت
- ⏱️ مؤقت دراسة (25/45/60 دقيقة + استراحة) والوقت بينضاف للإنجاز لحاله
- 🗓️ تقويم أيام الدراسة لآخر 5 أسابيع، ومخطط الصفحات لآخر 14 يوم
- 🏅 أوسمة، وسلسلة أيام متواصلة
- 📗 الفصل الثاني جاهز (بينضاف من ⚙️ الإعدادات لما ينزل)
- 🕌 بسم الله الرحمن الرحيم + خط أعداد لنسبة السنة كاملة وكل فصل لحال
- 🔄 مزامنة مشفّرة بين أجهزة محمد
